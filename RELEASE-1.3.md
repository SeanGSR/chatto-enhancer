# Chatto Enhancer v1.3.0

Chatto Enhancer 1.3 is rebuilt for **Chatto 0.6.0-beta.8**. It removes features now available natively and focuses on a private Personal Library that feels integrated with Chatto.

## New Features

- 🔖 Save messages privately from Chatto's native message menu
- 🔎 Search saved messages and jump back to the original message
- 📝 Create reusable message templates and insert them from the composer
- 🏷️ Add local nicknames, private notes, and tags to user profiles
- 🕘 Browse recently used GIFs
- 📚 Create custom GIF collections alongside Favorites
- ⚙️ Open native-style Enhancer settings from Chatto's top bar
- 🔀 Toggle GIFs, saved messages, templates, and local profiles independently

## Chatto 0.6 Cleanup

Removed extension features now provided by Chatto itself:

- emoji picker
- Markdown formatting controls
- themes
- participant volume controls
- call picture-in-picture

This also removes the old page-world bridge and reduces the extension's runtime surface.

## Improvements

- GIF icon and composer spacing now match native Chatto controls
- GIF, template, settings, and profile panels use Chatto's menu geometry and theme tokens
- Nicknames render across shared Chatto account-name surfaces
- Existing v1.2 nicknames and GIF favorites migrate automatically
- Import/export now includes saved messages, templates, profile notes, GIF history, and collections
- Feature changes apply immediately and synchronize between open Chatto tabs
