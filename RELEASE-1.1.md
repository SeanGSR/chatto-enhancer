# Chatto Enhancer v1.1

Feature update for **Chatto Enhancer**, focused on customization, settings, and support for additional Chatto servers.

## New Features

- 🖼️ Screen-share pop-out button for Picture-in-Picture viewing
- 🏷️ Local nicknames, visible only to you
- ⚙️ Settings popup with per-feature toggles
- 📤 Export and import for local extension data
- 🌍 One-click enable flow for self-hosted Chatto servers

## Privacy

New privacy-related behavior in this release:

- Nicknames and settings are stored locally using the browser storage API
- Access to additional Chatto servers is requested one site at a time and requires explicit browser approval

## Installation

Download the appropriate package below:

- **Chromium** — `chatto-enhancer-1.1-chromium.zip`
- **Firefox** — `chatto-enhancer-1.1-firefox.zip`

See the project README for installation instructions and supported browsers.
