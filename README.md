# Chatto Enhancer

Chatto Enhancer is a browser extension for Chatto that adds:

- per-person volume sliders in voice calls
- an emoji picker next to each message composer
- a markdown toolbar for Chatto's TipTap message editor

The extension runs only on:

- `https://chat.chatto.run/*`
- `https://chatto.pixel-box.net/*`

It does not add telemetry, analytics, remote scripts, or runtime network requests.

## Supported Browsers

- Chromium-based browsers with Manifest V3 support: Chrome, Edge, Brave, Opera, Vivaldi
- Firefox 140 or newer for full support

Firefox support depends on `world: "MAIN"` for the page-world bridge. Older Firefox versions may load the emoji and markdown fallback behavior, but the voice-volume bridge is not expected to work reliably.

## Privacy And Permissions

The extension requests only the `storage` permission.

Storage is used for:

- per-participant volume settings
- recently used emoji

The extension has host access only to the two Chatto origins listed above. The bundled emoji dataset is local, and no executable code is loaded from remote servers.

## Install From Release ZIP

Download the ZIP for your browser from a GitHub Release:

- `chatto-enhancer-1.11.1-chromium.zip`
- `chatto-enhancer-1.11.1-firefox.zip`

Unzip it somewhere permanent. Chromium browsers load unpacked extensions from the selected folder each time the browser starts.

## Chromium Developer Installation

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Select `dist/chromium/`
5. Reload your Chatto tab

For Brave, Edge, and similar browsers, use their equivalent extensions page such as `brave://extensions` or `edge://extensions`.

## Firefox Temporary Installation

1. Open `about:debugging`
2. Select **This Firefox**
3. Click **Load Temporary Add-on**
4. Select `dist/firefox/manifest.json`
5. Reload your Chatto tab

Temporary Firefox add-ons are removed when Firefox restarts. Permanent Firefox installation requires signing through addons.mozilla.org or a Firefox build/configuration that permits unsigned extensions.

## Local Development

Prerequisite: Node.js 20 or newer.

No runtime or development npm dependencies are used.

```sh
npm run check
npm run build
npm run package
```

Generated files are written to:

- `dist/chromium/`
- `dist/firefox/`
- `artifacts/chatto-enhancer-1.11.1-chromium.zip`
- `artifacts/chatto-enhancer-1.11.1-firefox.zip`

`dist/` and `artifacts/` are generated output and are not committed by default.

  styles.css
scripts/

The extension does not use a bundler. Browser builds are generated by copying audited source files into each target directory and writing a target-specific `manifest.json`.

## Features

**Volume:** A slider is added to each remote participant card while you are joined to a voice call. Drag, scroll, or use keyboard controls to adjust volume. Settings are stored locally by participant name.

**Emoji:** Click the smiley button beside a composer to open the bundled emoji picker. Search filters by emoji name. Recent emoji are stored locally.

**Markdown:** Select composer text to show a toolbar for bold, italic, strikethrough, heading, lists, quote, code, code block, and link. When available, formatting uses Chatto's TipTap editor commands through the page-world bridge. If the editor command is unavailable, the extension falls back to literal markdown insertion.

## Known Limitations

- Chatto DOM selectors are inferred from the current page structure and may need updates if Chatto changes its markup.
- A hostile script running in the same Chatto page origin can observe page-world objects and page messages. Bridge messages are validated and bounded, but same-origin page code is not a trust boundary.
- Firefox versions older than 140 may not support the required page-world behavior for voice volume control.
- Manual browser testing is required before publishing a release.
